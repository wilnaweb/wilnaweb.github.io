# Content

Esta pasta contém todo o conteúdo do WIL.DEV.

O conteúdo permanece completamente separado da implementação.

Cada idioma possui sua própria estrutura de arquivos.

A versão em inglês é considerada a fonte oficial.

A versão em português é produzida por localização manual.

## Estrutura

- Home
- About
- Expertise
- Case Studies
- Writing
- Career
- Learning
- Contact

Cada página possui exatamente um arquivo Markdown.

Os estudos de caso possuem arquivos independentes.

## Regras

- Nunca duplicar conteúdo.
- Nunca alterar a estrutura entre idiomas.
- Todo novo conteúdo deve ser criado primeiro em inglês.
- A tradução para português deve preservar contexto e significado.
