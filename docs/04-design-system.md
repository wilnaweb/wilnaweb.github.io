# WIL.DEV

# Documento 04 — Visual Design Direction

**Versão:** 1.0  
**Status:** Draft

---

# 1. Objetivo

Definir a direção visual da primeira versão do WIL.DEV.

Este documento estabelece os princípios de design que deverão orientar toda a experiência visual do projeto, garantindo consistência entre interface, conteúdo e identidade da marca.

Não define componentes específicos nem detalhes de implementação.

---

# 2. Conceito Visual

O WIL.DEV deverá transmitir a sensação de um produto de engenharia.

O visitante deve perceber imediatamente que está diante de um profissional com perfil técnico, organizado e experiente.

A interface deverá privilegiar:

- simplicidade;
- elegância;
- clareza;
- hierarquia visual;
- leitura confortável.

O design deverá desaparecer para que o conteúdo seja o protagonista.

---

# 3. Personalidade Visual

A interface deverá transmitir:

- Engenharia
- Precisão
- Organização
- Confiança
- Modernidade
- Elegância
- Sofisticação

Evitar qualquer característica que lembre templates genéricos ou sites promocionais.

---

# 4. Referências

A direção visual será inspirada em produtos digitais conhecidos pela simplicidade e qualidade de design.

Referências:

- Apple
- Vercel
- GitHub
- Stripe
- Linear
- Adobe

O objetivo não é copiar essas interfaces, mas compartilhar os mesmos princípios de design.

---

# 5. Princípios de Interface

## Minimalismo

Cada elemento da tela deve possuir um propósito.

Remover qualquer informação desnecessária.

---

## Espaço em Branco

Utilizar áreas amplas de respiro.

Evitar blocos excessivamente densos.

---

## Hierarquia

A leitura deve acontecer naturalmente.

Os títulos devem conduzir o visitante pelo conteúdo.

---

## Consistência

Todos os componentes deverão seguir o mesmo padrão visual.

---

## Performance

Evitar elementos gráficos pesados.

Priorizar carregamento rápido.

---

# 6. Estrutura Visual

A interface deverá seguir uma organização baseada em blocos verticais.

Cada seção possuirá um objetivo específico.

Exemplo:

Hero

↓

Resumo

↓

Especialidades

↓

Case Studies

↓

Writing

↓

Career

↓

Contact

---

# 7. Tipografia

A tipografia será um dos principais elementos da identidade.

Diretrizes:

- excelente legibilidade;
- poucos pesos;
- boa hierarquia;
- títulos fortes;
- textos confortáveis para leitura longa.

Evitar excesso de estilos diferentes.

---

# 8. Paleta de Cores

A paleta deverá ser neutra.

Cores principais:

- Branco
- Preto
- Tons de Cinza

Cor de destaque:

- Azul

O objetivo é destacar o conteúdo e não a interface.

---

# 9. Ícones

Os ícones deverão ser discretos.

Preferencialmente em estilo:

- Outline
- Minimalista

Nunca ilustrativos ou caricatos.

---

# 10. Animações

As animações deverão ser sutis.

Objetivos:

- melhorar percepção;
- reforçar transições;
- orientar a navegação.

Nunca chamar mais atenção do que o conteúdo.

---

# 11. Responsividade

O projeto será Mobile First.

O conteúdo deverá funcionar perfeitamente em:

- Desktop
- Notebook
- Tablet
- Smartphone

Sem perda de legibilidade.

---

# 12. Dark Mode

O Dark Mode fará parte da primeira versão.

As duas versões deverão possuir o mesmo nível de qualidade visual.

Nenhuma delas será considerada secundária.

---

# 13. Acessibilidade

A interface deverá seguir boas práticas de acessibilidade.

Prioridades:

- contraste adequado;
- navegação por teclado;
- estrutura semântica;
- textos alternativos;
- foco visível.

---

# 14. Experiência Esperada

Ao acessar o site, o visitante deverá ter a sensação de estar utilizando um produto de software moderno e bem construído, onde o design serve para destacar conhecimento, experiência e conteúdo, e não para competir com eles.

A percepção final deve ser de confiança, organização e maturidade técnica.
